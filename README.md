# 쉽(Ship)게 작업 — 프로토타입

운항 현장의 경험을 다음 정비와 다음 배의 설계로 잇는 해운 AI 피드백 루프.
「2026 해운/항만/물류 AX 혁신 아이디어 공모전」(한국해양진흥공사) 응모작의 시연용 프로토타입입니다. (팀 허니문)

**바로 보기:** https://d-dong-2.github.io/ship-ge-jakeop/

## 화면 흐름

1. **현장 안내** (선상 태블릿) — 교대 승선한 기관사에게 전에 탄 배와 달라진 점을 근거 문서 쪽수와 함께 안내하고, 같은 설비의 과거 사례를 미리 알려 줍니다. 매뉴얼에 질문하면 근거를 찾지 못할 때 ‘근거 없음’으로 답합니다.
2. **현장 피드백** (선상 태블릿) — 사진과 음성 한마디를 AI가 결함 보고로 정리하고, 기관장 확인 뒤 육상으로 보냅니다. 위성 통신이 끊기면 배 안에 저장했다가 연결되면 보냅니다.
3. **정비 지침 수정** (육상 웹) — 여러 배에서 반복되는 결함을 경고하고, 비슷한 사례를 근거로 정비 지침 수정안(1판 → 2판)을 만듭니다.
4. **새 배 사양 반영** (육상 웹) — 확정된 교훈을 새 배 도면과 대조하고 조선소에 보낼 의견 초안을 만듭니다. 고친 지침은 1단계 안내로 다시 돌아갑니다.

선박명, 설비 코드, 문서 쪽수, 도면 번호, 사례와 수치는 모두 시연용 가상 데이터입니다.

## 실행

- **화면만 보기:** `index.html`을 브라우저로 엽니다. 설치가 필요 없고, 인터넷이 없어도 시연용 데이터로 동작합니다.
- **실제 AI 서버와 연결:**
  ```bash
  python server/app.py          # 파이썬 3.9 이상, 추가 설치 없음
  ```
  화면 오른쪽 위 **연결 설정**에서 ‘실제 AI 서버(API)’를 고르고 `http://localhost:8787`을 넣은 뒤 **연결 확인 → 저장**을 누릅니다.

  LLM을 붙이려면 서버를 켜기 전에 환경 변수를 넣습니다. 넣지 않으면 문서 검색 결과를 그대로 근거로 보여 줍니다.
  ```bash
  export LLM_API_URL=https://api.openai.com/v1/chat/completions   # OpenAI 호환 주소
  export LLM_API_KEY=...                                          # 키는 서버에만 둡니다
  export LLM_MODEL=...
  ```

## 구조

```
index.html            화면 전체 (HTML·CSS·JS 한 파일)
                       └ DemoApi(가상 데이터) / HttpApi(실제 서버) 두 가지 데이터 계층
docs/API.md           화면과 서버가 주고받는 형식
server/app.py         API 서버 시작 코드 (검색 + 선택적 LLM 생성)
server/data/demo.json 시연용 데이터
server/data/docs/     검색 대상 문서 (시연용 가상 매뉴얼)
```

실제 서비스로 바꿀 때 손볼 곳은 `docs/API.md` 마지막 표에 정리했습니다.
